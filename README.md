# Вулиці міста Львова

Web-застосунок на фреймворку Express із шаблонізатором Ejs та базою даних NeDB.

## Склад проєкту

```
app.js              програма web-сервера застосунку
db/streets.db       колекція вулиць
db/houses.db        колекція будинків
views/streets.ejs   шаблон сторінки львівських вулиць
views/houses.ejs    шаблон сторінки будинків вибраної вулиці
views/error.ejs     шаблон сторінки повідомлення про помилку
public/style.css    таблиця стилів
package.json        опис проєкту та його залежностей
```

## Запуск

```
npm install
node app.js
```

```
Сервер почав прослуховувати порт 3000…
```

## Сторінки

| Маршрут        | Сторінка                                         |
|----------------|--------------------------------------------------|
| `/`            | список львівських вулиць з назвою та районом      |
| `/streets/:id` | список будинків, розташованих на вибраній вулиці  |

З першої сторінки посиланням «переглянути» виконується перехід на другу, з
другої посиланням «До списку вулиць» — назад.

## Робота програми

`app.set('view engine', 'ejs')` призначає застосунку шаблонізатор Ejs,
`express.static` — каталог статичних файлів.

Обробник маршруту `/` читає колекцію вулиць методом `findAsync`, сортує за
назвою і передає масив у шаблон `streets.ejs`. Шаблон циклом `forEach` будує
рядки таблиці.

Обробник маршруту `/streets/:id` за параметром маршруту знаходить вулицю, а
потім вибирає з колекції будинків записи, поле `street` яких дорівнює її
ідентифікатору. Якщо вулиці немає — відповідь зі станом 404.

Проміжковий обробник з чотирма параметрами перехоплює помилки, виводить обʼєкт
помилки в консоль і повертає сторінку зі станом 500.

## Перевірка

Node.js v25.2.1, express 5.2.1, ejs 6.0.1, @seald-io/nedb 4.1.2, порт 3103.

Сторінка `/` повернула таблицю з трьома вулицями, сторінка `/streets/s3` —
таблицю з двома будинками на площі Ринок (Чорна камʼяниця 1580, камʼяниця
Корнякта 1580).
